## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/92eleven/Kavaro.git
cd Kavaro

# Copy and configure environment
cp .env.example .env
nano .env

# Edit your qualification criteria
nano knowledge_base.json

# Launch
docker compose up -d

# Verify
curl http://localhost:8080/health
```
